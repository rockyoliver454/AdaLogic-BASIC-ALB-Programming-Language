# Code of Conduct — AdaLogic BASIC

Contact: **contact@alb-lang.org** · https://alb-lang.org

## Our pledge

We pledge to make participation in the AdaLogic BASIC project a
harassment-free experience for everyone, regardless of age, body size,
visible or invisible disability, ethnicity, sex characteristics, gender
identity and expression, level of experience, education, socio-economic
status, nationality, personal appearance, race, religion, or sexual
identity and orientation.

## Our standards

**Welcome:** empathy and kindness; respectful disagreement; constructive
feedback; focus on what is best for the community; grace when others
err.

**Unwelcome:** sexualized language or imagery; trolling, insults,
derogatory comments, personal or political attacks; public or private
harassment; publishing others' private information without permission;
sustained disruption; any conduct a reasonable person would consider
inappropriate in a professional setting.

## Scope

This code applies in all project spaces (issues, pull requests,
discussions, chat, events) and when representing the project publicly.

## Enforcement

- **Report:** write to **contact@alb-lang.org** with links/screenshots
  and context. Reports are confidential.
- **Review:** the maintainer investigates promptly and fairly.
- **Consequences** (escalating): private correction → public warning →
  temporary interaction ban → permanent ban from project spaces.

Maintainers who do not follow or enforce this code in good faith face
the same consequences. Retaliation against reporters is itself a
violation.
